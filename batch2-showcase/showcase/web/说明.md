# 网页版介绍（HTML）

## 文件
- **单文件版**：`GPU调度管理器-介绍-单文件.html` —— 双击即可，图片已内嵌，294 KB，发给别人不会掉图。
- **文件夹版**：`index.html` + `assets/` —— 改内容用这个，图片是原图。
- `预览/` —— 七页的静态截图，用于快速查看。

用 Chrome / Edge 打开，按 `F` 全屏。

## 操作
| 按键 | 作用 |
|---|---|
| `→` `↓` `空格` `滚轮` | 下一页 |
| `←` `↑` | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| `F` | 全屏 |
| `R` | 自动播放（每 7 秒一页，光标自动隐藏） |
| `Esc` | 退出全屏 |

也支持触屏上下滑。地址加 `?p=5` 可以直接跳到第 5 页。

## 视觉
深色工业排版：近黑底（#0B0B0C）+ 80 px 细网格 + 单一酸性绿（#CDFF4A）+ 等宽字标签。
不用玻璃、不用渐变卡片、不用圆角——和软件本身的浅色极光界面刻意分开，避免"海报就是软件截图放大版"。

字级：封面 80 / 页标题 48 / 正文 17.5 / 标签 11，数字与编号一律等宽字体。

## 动效
全部由 CSS 变换 + JS 逐帧控制，没有用任何转场库。

**翻页**：两页交叉，不是先黑再亮。旧页 0.34 秒后退（缩到 95.5%、上移 32px）淡出；新页同时从 46px、97.2% 落位，0.72 秒。方向是感知的——前进从下往上，后退从上往下。同时一道 240px 高的扫描光从顶扫到底，末尾带一条 1px 亮线。

**标题**：逐字 3D 立起。每个字初始 `rotateX(-40deg)` + 下沉 108%，按 16ms 间隔依次归位，整行 0.8 秒完成。

**编号**：`02 / 03 …` 从上方翻入，用 clip 遮罩裁切，像机械计数器。

**列表**：每一条用 `clip-path` 从上往下抽出来，不是淡入——所以能看见边框先出现、文字跟着露头。

**截图**：带透视抬起。初始 `rotateX(9deg)` 后仰 30px，落位时图片本身从 1.05 缩回 1，像从桌面立起来。

**显存条**：五段按宽度依次生长（每段 66ms 错峰），最后一段斜纹持续流动。

**时间轴**：1px 线 1.9 秒画到底，四个节点在被扫到时依次弹亮，各带一圈扩散光晕。

**表格**：行从左侧滑入；「已实测」整行落位后闪一次酸绿色底。

**代码块**：横向「打印」揭示，像终端在读出来。

**常驻**：网格 52 秒漂移一格，左上角光斑 9 秒呼吸。都是合成层动画，不占 CPU。

## 录成视频
1. 按 `R` 自动播放，或手动按 `→` 控制节奏；
2. 用 OBS（窗口采集）或 `Win + Alt + R` 录屏；
3. 改自动播放时长：搜 `7000`（毫秒），改成 5000 / 9000 都行。

## 改内容
- 文字直接改 HTML。
- 颜色只动 `:root` 里的 `--acid`（强调色）、`--bg`（底色）、`--ink*`（文字灰阶）。
- 想换成浅色版：把 `--bg` 改 `#F4F4F0`、`--ink` 改 `#0B0B0C`、`--line` 改深色，其余沿用。
- 加页：复制一个 `<section class="scene">`，改 `eyebrow` 的编号和页脚 `NN / 10`，JS 会自动识别总页数。
- 截图路径写成 `assets/xxx.png`，重新生成单文件版时会被自动内嵌。
