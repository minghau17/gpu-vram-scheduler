# 交付说明 · GPU 调度管理器 3.0

## 怎么用

1. 双击 `GPU调度管理器-win32-x64\GPU调度管理器.exe`（免安装，不需要 Node/运行库）。
2. 打开后先看**概览**：左边是独显真实占用，右边是「可释放 / 建议迁移 / 已实测」三个数。
3. 想省显存，两种方式：
   - 点 **一键智能优化** → 勾选清单 → 应用（后台程序批量走核显）；
   - 进 **应用调度** → 单个程序点「核显」，或勾选多行批量迁移。
4. 上面任何一步之后，程序都只是**写了偏好**。到 **应用调度** 找到带「待重启」标记的行，
   点右侧 `···` → `重启以生效`，或者自己关掉再打开。
5. 想知道到底省了多少：进 **收益实测** → 选几个目标 → **开始实测**。
   它会先量 15 秒基线，再写偏好，等你重启，重启后再量 15 秒，最后给出净释放量和置信度。
6. 需要交报告：右上角 **导出报告**，生成 Markdown 到 `%APPDATA%\GPU调度管理器\data\reports`。

## 三个数字别弄混

- **可释放（待重启）**：已经设成核显、但进程还没重启，所以显存还没还回来。
- **建议迁移预估**：还没动、但适合迁到核显的程序当前占用之和，是"还能再省多少"。
- **已实测释放**：真正量出来的差值，累加值，只有重启过的会话才算。

## 图标

- 一套多尺寸：`assets/icons/logo.svg`（矢量源）、`icon-1024/512/256/128/64/48/32/24/16.png`、`app.ico`。
- 已写进 exe 资源，任务栏、开始菜单、窗口标题栏都用它。

## 建议你先做的一件事

进 **设置 → 自动分流**，打开开关，勾选「浏览器 / 通讯 / 办公 / 下载」。
之后新开的这类程序会自动走核显，不用每次手动点。

## 我在这台机器上做过的改动（请知悉）

调试「实测」链路时，我确实点过几次「切到核显」，因此下列程序当前已被写成 `GpuPreference=1`，
重启后它们会走核显（不影响独显程序）：

- Steam Client WebHelper、MCHOSE HUB、WeChatAppEx、DeskBox、Google Chrome、
  Wallpaper Engine、WidgetBoard、Microsoft Edge WebView2 等（以应用调度页「核显 9」为准）。

不想要的话，在应用调度里把对应行改回「自动」即可，随时可逆；注册表还原本工具只改
`HKCU\Software\Microsoft\DirectX\UserGpuPreferences` 里那一条值的 `GpuPreference` 字段。
